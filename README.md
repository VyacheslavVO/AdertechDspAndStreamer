# Adertech DSP and Streamer
Приложение `OS Android 11 (Android API 30 or later)` и выше для управления семейством аудио процессоров `Adertech`, выпущенных до 2026 года + приставка аудио стриминга `Adertech`.
По сути это приложение для управления одним аудио выходом аудио процессора и стримером в "одном приложении". Тестировалось это на панели управления (планшете) `Adertech 10" 1280x800 160 dpi`.  
Этот проект — продолжение [предыдущей реализации](https://github.com/VyacheslavVO/AdertechDspApp_v1)

## Как это подружить?
1. Запускаем приложение
2. Переходим в раздел `настойки` и настраиваем подключения к устройсвам (необходимо в сети заранее адреса устройств сделать статическими)
3. Далее отредактировать во вкладке `Editor` для читабельности входы и выход аудио процессора
4. Загрузить любимую музыку в панель и аудиостример — эта формальность для наглядности, но я уверен, она хороша для повседневного использования
5. Переоткрываем приложение и пользуемся
